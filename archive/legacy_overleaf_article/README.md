# Overleaf package

Upload this entire folder to a blank Overleaf project and set `main.tex` as the
main document.  Compile with **XeLaTeX**.  Overleaf will run BibTeX automatically;
if references initially appear as question marks, use **Recompile from scratch**.

The journal-style body has exactly six numbered sections:

1. Introduction
2. Mean-Reverting Markov Processes
3. Mean-Reverting Processes from Monotone Diffusion Transforms
4. Mean-Reverting Processes from Mixed Copula Families
5. Empirical Analysis
6. Conclusion

Detailed proofs and the implementation/provenance audit follow as appendices.
All figures required for compilation are included in `figures/`, and all
references are managed in `references.bib`.
