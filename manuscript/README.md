# Canonical manuscript sources

- `source/meanreversion_article_theory_revised.tex`: corrected theory source
  from which the submission's theory and proof sections are generated.
- `source/article_references.bib`: complete bibliography for the integrated
  article.
- `source/meanreversion_theory_references.bib`: bibliography for the standalone
  corrected-theory document and its audit.
- `audits/`: detailed derivation audit and correction-comparison report.

Generated submission sections should be rebuilt with
`scripts/19_build_submission_paper.py`, not edited as a second theory source.
